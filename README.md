# Python Learning Journey 🚀

Welcome to my Python learning repository! This project tracks my progress as I dive into Python, starting from fundamental basics and moving towards advanced backend development.

## 📁 Project Structure

- `python_basic/`: Core Python syntax, control flow, input/output, and fundamental logic.
- `complete_backend/`: Advanced backend development projects (Django, FastAPI, Flask).

---

## 🐍 Python Basic Learning

Explore the building blocks of Python logic and syntax.

### Day 1: Inputs, Variables, and Control Flow
The first day focused on user interaction, data handling, and multi-condition logic.

#### 🛠️ Exercises:
1.  **Salary Calculator (`day_1_salary_calculator.py`)**
    *   Handles complex inputs (name, salary, bonus, reimbursements).
    *   Uses **f-strings** for dynamic reporting of total income.

2.  **User Profile Logic (`day_1_user_profile.py`)**
    *   Collects detailed user data (age, city, profession).
    *   Implements **Boolean logic** for simple profile categorization.

3.  **Core Logic Testing (`day_1_test.py`)**
    *   A consolidated testing file containing multiple real-world scenarios.
    *   **Note:** To keep things organized in a single file, previous exercises are commented out while working on new ones.
    *   **Features:**
        *   **Salary Tax Calculator**: Implements tiered tax logic using `if-elif-else`.
        *   **Login System**: Nested logic for credential verification and age restriction.
        *   **ATM Simulator**: A robust simulation covering PIN verification, withdrawal limits, and balance management.

### Day 2: Loops, Lists, and Business Logic
The second day focused on iteration, list manipulation, and data filtering techniques.

#### 🛠️ Exercises:
1.  **Order Analysis (`day_2_order_analysis.py`)**
    *   **Loop Control**: Demonstrates `range()` for even numbers and `continue` to skip specific multiples.
    *   **Data Filtering**: Categorizes orders into High, Processing, or Valid based on value thresholds.
    *   **List Logic**: Implements an algorithm to find the **Highest** and **Second Highest** values in a collection without built-in sorting functions.

### Day 3: List Transformations and Logic
The third day focused on advanced list operations, filtering, and manual indexing.

#### 🛠️ Exercises:
1.  **List Logic (`day_3_list_logic.py`)**
    *   **Filtering & Transformation**: Implements logic for separating even/odd numbers and removing duplicates.
    *   **Conditional Counting**: Logic to count elements meeting specific thresholds.
    *   **Indexing & Reversing**: Demonstrates manual list reversal using `range()` and negative step indexing.

I prefer keeping small code tests in a single file by commenting out previous versions. This allows for a quick reference of my learning progression without cluttering the workspace with many small files.
